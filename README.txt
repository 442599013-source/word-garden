WordMatch V4.1 · Approved design

Upload index.html and wordmatch-game.html to the ROOT of your GitHub Pages word-garden repository. Both pages are self-contained (all art embedded).

Gameplay: touch QWERTY keyboard to type matching word; full word flies from word list into learning panel and disappears; progress stored locally.

The layout uses the approved 841x1870 design image at native aspect ratio without stretching. Dynamic text is drawn once over blanked panels; the keyboard is the original image with clickable hit areas.

This package does not claim Microsoft Azure speech support. Azure Worker compatibility still needs deployment and end-to-end validation.
