V30：临时录音备用识别补丁

适用基础：已上传V29及之前的单词显示修复。本包只增加临时录音备用识别，不重传题库或其他旧补丁。
界面不增加框框、按钮或布局；仍使用现有话筒、停止按钮、输入框和提示条。

必须完成下面两步，单独上传网页文件不能启用备用识别。

第一步：更新现有 Cloudflare 语音服务
1. 打开 Cloudflare，进入 Workers & Pages，选择原来的 wordmatch-voice。
2. 点击 Edit code，用本包 cloudflare/worker.js 的完整内容替换当前代码，保存并 Deploy。
3. 保留现有 AZURE_SPEECH_KEY、AZURE_SPEECH_REGION（原配置为 eastus）及 AUDIO_CACHE 绑定，不删除、不更换。
4. 浏览器打开 https://wordmatch-voice.442599013.workers.dev/health 。看到 version 为 audio-backup-v1、sttReady 为 true，说明新代码和密钥配置已就位；这不是实际识别成功的保证，仍需下一步试读。
此代码保留原有 /tts 朗读及其缓存，仅新增 /stt 短录音识别；识别使用原来的 Azure Speech 资源。

第二步：更新游戏网页
把本包 site 文件夹里面的文件上传到 GitHub 仓库原来的网页根目录，按原文件名覆盖；不要把 site 文件夹本身作为新目录上传。
新增 wm-audio-backup.js 和 wm-pcm-capture.js 必须一并上传。
Cloudflare 的 worker.js 不要当作网页脚本导入。该文件需要按第一步部署。
完成后重新打开游戏页面。

使用方式
点原来的话筒，浏览器按需要请求麦克风权限。准备好后正常说话。
实时识别正确时沿用原来的流程，不上传录音。
实时识别没有文字、只有部分文字或未匹配当前句子时，说完后点原来的“停止”；后台用临时录音识别，结果写入原来的输入框。
备用识别等待期间仅复用现有提示条。继续打字、切题或取消会终止旧请求，避免覆盖新答案。

录音处理
录音最多45秒，只暂存在当前网页内存，不写手机文件、localStorage、IndexedDB、Cache API或云端KV/音频库。
仅备用识别时临时上传处理；处理结束、退出本次录音或取消后释放内存及麦克风。
网络临时故障最多自动重试一次，不无限请求；完全断网时仍无法完成在线识别。
网页刷新/关闭后无法找回这份临时录音，这是不持久保存的结果。
备用识别会计入现有Azure Speech识别服务用量或额度，不需要新建云端录音存储。

验证范围
模拟测试通过：实时文字即时回填、实时成功不上传、无结果/部分结果触发备用识别、备用失败保留已有文字、取消后旧结果忽略、音频重采样为16kHz单声道PCM WAV、录音内存清理与麦克风释放、短暂网络重试、服务请求格式和来源验证、原朗读缓存不受影响。
真实iPhone双路收音兼容、现有Azure账户识别权限/额度以及云端部署未能在本次环境验证，部署后需实际试读。没有把未经验证的收音问题宣称为已彻底解决。

请不要上传之前那个 SpeechResult_Fix 包；本包的识别脚本是完整替换，不依赖那个收尾补丁。
