WordMatch V47 基于 V43 的完整独立文件包

1. 本包直接从你上传的 WordMatch_V43_Update(1).zip (64文件)构建，包含全部原V43基础资源，并非仅含补丁。
2. 解压后把 WordMatch_V47_Full 文件夹内的所有文件一次上传到 GitHub 仓库 main 分支根目录（与原 index.html 同级），覆盖同名文件。不要把外层文件夹一起上传。
3. GitHub Pages 必须从 main /(root) 发布，否则上传成功页面也不会更新。打开网站时可在网址末尾加 ?v=47.1 强制绕开旧HTML缓存。
4. 首页、游戏页现由新 v47-home.css/js 和 v47-game.css/js 渲染，而基础V43数据、动画和引擎保留。

6. Hint提示使用原有微软配音服务，网络服务失败时朗读可能不可用；根据原设置关闭语音时亦不会朗读。
7. 当前完成静态文件/JS语法检测；真实iPhone、GitHub Pages、Work预览完整一致性需要线上验证。建议先部署独立测试分支。
