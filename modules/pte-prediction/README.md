# PTE自动预测模块 / PTE Prediction

## 目标分数
- 听力 Listening：58
- 口语 Speaking：76
- 阅读 Reading：59
- 写作 Writing：69

## 自动预测
- 根据用户在游戏中的学习、练习、考试表现自动预测PTE四项分数。
- 不允许要求用户手动输入预测分数。
- 随学习记录自动更新预测分数。
- 没有有效数据时显示待评估。
- 预测模型尚待开发和验证，不得使用随意编造的公式冒充可靠预测。

## 进度显示
- 每项显示预测分数、目标分数、完成百分比和进度条。
- 四项分别计算，自动同步更新。

## 排版保护
- 保留用户确认的原版首页及PTE区域布局。
- 未经用户要求，不得移动、删除、重新设计原有模块。

## 修改原则
- 每次只更新指定模块。
- 修改前保留旧版，修改后检查功能。
- 不得删除已经确认的功能。
